# Hardware

LinBridge has three hardware phases:

- [`prototype/`](prototype/) documents the completed narrow development board
  used for initial LIN research and validation.
- [`linbridge-2.0/`](linbridge-2.0/) contains the validated square
  relay-replacement hardware design and its historical manufacturing candidates.
- [`linbridge-3.0/`](linbridge-3.0/) contains the Rev A design and the immutable
  package used for the board ordered on 2026-08-19. Hardware validation is
  pending.

Hardware design files are published for documentation and evaluation. The final
hardware license has not yet been selected.
