# LinBridge prototype / development board

The narrow two-layer board was the initial development platform. It was used to
establish the power and LIN physical layers, LIN master timing, wake-up, polling,
button decoding, the web diagnostic workflow and basic illumination control.

This board is a completed proof of concept. It is preserved as evidence of the
project's evolution, receives no new features and is not a target for canonical
firmware or future hardware releases.

No prototype manufacturing or design files have been selected for public release
in this repository yet.
