# LinBridge 3.0 revision documents

Revision-specific design notes, risk analysis, pinout documentation, and
hardware validation records belong here. Documents must distinguish verified
Rev A production evidence from later analysis or proposed Rev B changes.

- [`technical-report.md`](technical-report.md) records the PCB optimization,
  Rev A functional blocks, external pinout, source discrepancies, and the risk
  register prepared after the board order.
