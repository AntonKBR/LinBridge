# Firmware

The repository currently preserves the legacy ESP32 Wi-Fi prototype firmware
used during development. Identification and verification of the canonical
LinBridge 2.0 firmware are still pending.

- [`legacy/esp32-wifi-prototype/`](legacy/esp32-wifi-prototype/) preserves the
  existing historical implementation without functional changes.
- [`linbridge-2.0/`](linbridge-2.0/) records the status of the future canonical
  firmware target.
