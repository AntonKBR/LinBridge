# Public source register

The LinBridge research dossier was reconstructed from the following evidence
classes:

- bench logs and recorded electrical observations;
- firmware source and Git history;
- schematic exports;
- editable PCB sources and PCB layout exports;
- BOM revisions;
- Gerber and drill packages;
- photographs and bench screenshots;
- archived engineering discussions.

Measurements, retained firmware behavior, schematics, PCB nets and manufacturing
artifacts take precedence over proposals or unverified statements in engineering
discussions.

The raw discussion archive, complete local file inventory, local paths, private
file names and internal archive identifiers are retained outside the public Git
content. They are not required to understand the conclusions documented here.

Some exceptionally long source messages were truncated by the original export
interface. No conclusion is claimed from unavailable content.
